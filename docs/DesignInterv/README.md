# System-Design Learning References

This directory contains curated system-design reference material used by Blue Garden's learning content.

It is an **active content directory**, not historical documentation. The learning registry currently validates local source paths with the prefix `docs/DesignInterv/`, and structured learning content references files here.

Do not rename or move this directory without updating:

- `src/domain/learning/registry.ts`;
- `src/domain/learning/structuredContent.ts`;
- relevant tests/content references.

The files cover topics such as caching, sharding, rate limiting, object storage, feeds, API diagnosis, file upload architecture, and related system-design interview material.
